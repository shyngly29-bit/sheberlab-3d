# ШеберLab 3D: демоверсия

Образовательное веб-приложение для художественного труда. На каждую учебную тему делается отдельный HTML-симулятор: ученик выполняет операции, видит последствия ошибок и получает формативную обратную связь. Интерфейс на казахском языке.

## Запуск

Сборка не нужна: Three.js 0.160 и GSAP 3.12.5 загружаются с CDN, поэтому требуется интернет.

**Вариант 1: без установки (Windows)**
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -port 8093
```
Затем откройте http://localhost:8093

**Вариант 2: Python**
```powershell
python -m http.server 8093
```

**Вариант 3: Vite (нужен Node.js)**
```powershell
npm install
npm run dev
```

**Статический хостинг** (GitHub Pages, Netlify): загрузите папку как есть.

> Файл `index.html` нельзя открывать двойным щелчком (`file://`): ES-модули работают только через сервер.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Главная: 3D-мастерская, scroll storytelling, каталог, раздел ценности, окно симулятора |
| `idea.html` | Страница «Педагогикалық идея» со сценарием показа на 3–5 минут |
| `src/styles.css` | Стили, палитра, адаптив, `prefers-reduced-motion` |
| `src/main.js` | Связка страницы: GSAP ScrollTrigger, каталог, открытие симулятора |
| `src/scene.js` | Только визуализация: `HeroScene` (главная) и `SimView` (сцена симулятора) |
| `src/simulator.js` | Педагогическая логика: 6 этапов, проверки, обратная связь |
| `src/assessment.js` | Рубрика, баллы, рекомендации, LocalStorage |
| `src/modules.js` | Конфигурация модулей и тем: все тексты, диапазоны, критерии |

## Как устроено оценивание

Пять критериев, по 2 балла за каждый, всего 10. Баллы начисляются только за действия ученика, прокрутка на них не влияет:

- **Материал.** Фанера даёт 2, сосна 1, МДФ 0. Если правильный материал выбран со второй попытки, максимум 1.
- **Измерение.** Всё верно с первой проверки — 2, со 2-й или 3-й — 1, позже — 0.
- **Разметка.** ±2 мм с первой попытки — 2, ±2 мм позже или ±5 мм — 1, иначе 0.
- **Последовательность.** Ошибки: работа без техники безопасности, не тот инструмент, нарушенный порядок. 0 ошибок — 2, 1–2 ошибки — 1, 3 и больше — 0.
- **Сборка.** Ошибки: сборка без клея, нарушенный порядок, неверный угол. Шкала та же, что у последовательности.

Прогресс и история последних 10 результатов хранятся в LocalStorage браузера. Если вернуться к этапу и что-то изменить, следующие этапы придётся пройти заново.

## Как учителю изменить или добавить тему

1. Откройте `src/modules.js`.
2. **Изменить текущую тему.** Правьте тексты, диапазоны `dims.*.ok`, цель разметки `marking.target`, порядок `sequence` и критерии `criteria`. Код трогать не нужно.
3. **Новая тема по тому же сценарию** (заготовка → разметка → обработка → сборка), например «Ағаш кесу тақтайшасы». Скопируйте объект `WOOD_PHONE_STAND`, переименуйте его, поменяйте `id`, `title` и значения. Затем добавьте карточку в `MODULES` с полем `sim: ВАШ_ОБЪЕКТ` и `status: 'ready'`.
4. **Модуль с другими действиями** (шитьё, орнамент). Нужны новые методы в `SimView` (`scene.js`) и новые функции этапов в `simulator.js`. Оценивание (`assessment.js`) переиспользуется без изменений.
5. Пока модуль не готов, оставьте `sim: null`, `status: 'demo'`: карточка покажется с честной пометкой «әзірленуде».

## Что проверено

- Главная: 3D-сцена, камера по прокрутке (4 точки), подписи, ошибок в консоли нет.
- Симулятор: прохождение всех 6 этапов, начисление баллов с ошибками (3/10) и без ошибок (10/10), сохранение и «Жалғастыру» после перезагрузки, перезапуск, запись истории.
- Ширина 375 px: нет горизонтального скролла, 3D-окно сверху, панель снизу.

## Что не проверено

- Реальные устройства (iPhone, Android, интерактивная доска), Safari.
- Плавность анимаций: при проверке панель браузера была скрыта, поэтому `requestAnimationFrame` тормозился. Логику этапов проверял с мгновенными анимациями.
- Работа без интернета: нужно скачать `three` и `gsap` локально и поправить ссылки в `index.html`.
- Режим без WebGL: код запасного варианта написан, но в браузере не проверен.
